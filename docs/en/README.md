# UWdeVST — Piano, Bass & Guitar

Three independent synthesizers for keyboards, bass lines and guitar colours. Sound is generated by synthesis; no sample-library download is required.

**[Downloads](../TELECHARGEMENTS.md) · [Installation](../INSTALLATION.md)**

- **Bass:** 9 models across acoustic-inspired, electric, 808 and synthetic colours. Featured following human listening approval of the auditioned material.
- **Guitar:** 9 models in acoustic, electric and electronic families. Featured following human listening approval of the auditioned material.
- **Piano:** 8 keyboard models. Prepared Piano, Rhodes, Wurlitzer and Clavinet corrections were accepted in local auditions on 29 September 2026; the grouped sources contain candidate v3. The preserved Piano 1.0.2 downloads predate these corrections.

Windows x64 and Linux x86_64 distributions contain VST3 and Standalone formats. macOS downloads are source builders requiring compilation on a Mac.

The original 1.0.2 files are transferred unchanged. This repository does not announce a new binary release. See the [included proprietary licence](../../LICENSE.md) for the exact terms.
