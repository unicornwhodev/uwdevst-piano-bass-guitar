# UWdeVST Guitar

9 modèles organisés en trois familles : acoustique, électrique et électronique. Presets Reference et Signature.

## Jouer

Choisir la famille et le preset, puis jouer une phrase adaptée au registre de la guitare. Essayer les nuances de vélocité avant d’ajouter des effets.

## Version disponible

Validation humaine acquise pour les versions auditionnées. Elle ne constitue pas une validation de tous les presets dans tous les hôtes.
