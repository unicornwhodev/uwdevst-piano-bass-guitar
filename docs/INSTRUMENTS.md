# Choisir un instrument

| Besoin musical | Instrument |
| --- | --- |
| Une ligne de basse, un grave électronique ou une basse 808 | [Bass](BASS.md) |
| Une partie de guitare, un riff, une couleur de cordes | [Guitar](GUITAR.md) |
| Un clavier acoustique, électrique ou préparé | [Piano](PIANO.md) |

Chaque synthétiseur possède sa propre application et son propre VST3. Ils peuvent être utilisés indépendamment ou sur trois pistes d’un même projet.
