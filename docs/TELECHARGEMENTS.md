## Vérifier un fichier

Les distributions officielles 1.0.2 sont conservées à l’identique. Les [sommes SHA-256](SHA256SUMS.txt) permettent de contrôler un téléchargement :

```powershell
Get-FileHash -Algorithm SHA256 '.\nom-du-fichier.zip'
```
